# 商品驾驶舱日表接入与快速建表

> 历史说明：本文引用的 evidence 文件、截图和日志仅本机保管，不随 Git 仓库分发；历史测试结果不代表本次或云端验证。

本次版本1.4.0，数据库schema4；独立数据服务，不修改经营看板项目。源接口 `B08GhuIzQB` 对应 `ads_product_dashboard_daily`。用户原始DDL见 `ads_product_dashboard_daily.sql`，本地类型定义见 `../config/ads_product_dashboard_daily.dataset.example.json`。

## 快速配置路径

1. 数据表 → 新建数据表 → 从建表语句快速导入。粘贴一条CREATE TABLE，点击解析并预览。
2. 读取字段名、类型、中文COMMENT与已声明PRIMARY KEY。没有声明的唯一键不会推测；用户本表选 `daily_id`，业务日期选 `dt`。业务日期应用后成为必填date维度。
3. 检查每行说明、金额类型、文本长度和分组用途。预览只生成草稿；点击“应用并替换当前字段”后，仍需“创建数据表”。手工建表保留。
4. 接口接入 → 配置来源，选刚建的表，填写请求地址、协议、接口ID、鉴权、分页；默认按同名字段映射，可逐项调整或确认重置为同名。
5. 先测试一页，再发起日期同步。全部分页完成、校验通过后原子发布。测试一页不表示整个日期已导入。
6. 对外使用数据查询接口，或在“开放接口”保存日期范围/分组/汇总/公式/排序规则；只授权已配置表的机器密钥，不会因建表自动开放权限。

支持的DDL是受限元数据描述，不是任意SQL入口。支持常用字符、整数、浮点/十进制、日期时间、布尔类型和NULL/NOT NULL/COMMENT/PRIMARY KEY；末尾COMMENT与本例RANDOM BUCKETS被识别，分桶设置不会本地执行。不支持的引擎、默认表达式、其他约束/索引、复杂建表或多语句会明确报错。最多64 KiB、80列；不自动执行原始DDL或脚本。

## 本表已确认的存储选择

- 50个字段完整保留，每列中文说明同时写入元数据和数据库列注释；唯一键 `daily_id`，不重新计算源ID；商品ID仍为文本。
- `dt` 为业务日期date；接口返回日期时间时按北京时间取自然日。
- 37个金额、数量、比率等数值字段使用NUMERIC(38,6)。`net_sales_amount`虽然源DDL为VARCHAR，真实值为数值文本，按已确认净销售额含义显式改为decimal。不会静默舍入或截断；超精度/超范围拒绝整日发布。
- 数量保留decimal以兼容源DOUBLE及十进制文本；没有强制转整数。源率只作为明细存储，周期比率需用汇总分子/汇总分母重算。
- 12个文本字段最大10000字符；源VARCHAR(1048576)不原样复制，超长值拒绝，绝不截断。
- `product_exp_score`、`shop_overall_exp_score`实际含文本占位符，保留string及原值，不强制转0或NULL。
- `listing_time`源值没有时区，本次按string保留原文；不是凭空添加时区。未来确需时间运算应明确源时区并新建带转换规则的表。
- 用户明确确认 `owner_person` 的CRLF、CR、LF、TAB替换为空格，NULL保留；已有空格不折叠，首尾不裁剪，其他字段不处理。配置项为 `text_whitespace_fields: ["owner_person"]`，默认空列表，原来源行为不变。
- 同名映射50/50，分页从1开始，每页200，最多20次/秒供应商限制下配置2次/秒、有限重试。来源凭据由后台加密保存，不进入示例或镜像。
- 按主键更新，同一日同一ID整行覆盖、新ID增加、未返回旧记录保留；自动定时同步默认关闭。保留180天不等于已自动回补180天。

## 数据口径边界

总成交金额/支付金额采用pay_amount；净销售额直接采用net_sales_amount；周期、店铺等维度利润采用profit_amount；单链接单天支付预估采用profit_pay_est。退款率按聚合refund_amount除聚合pay_amount；其他已确认成本/利润占比以净销售额作分母，分母0按现有引擎返回NULL。费用之间可能包含，不能无确认地全部相加。此接入不会自动配置未确认的经营公式、评分阈值或同比。

## 升级、备份与回滚

没有增加数据库迁移，schema仍为4。部署前保存1.3.0源码和数据库快照，记录旧表/来源/账号指纹。升级api、worker、init到1.4.0后才保存新的文本转换配置。

**不能仅回退1.3.0镜像连接新配置库**：旧SourceConfig拒绝未知的text_whitespace_fields。回退前先备份1.4.0当前库和配置，以保存新表与新同步数据；把升级前快照恢复到一个新库，使用对应1.3.0镜像和原加密密钥/配置连接恢复库。不得直接删除真实新表或清洗线上配置来凑兼容。恢复库验证通过后再切换连接；升级后新增数据需从新备份保留或经新版本重新同步。
